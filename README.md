# 🚀 Leetcode-GeeksforGeeks

My solutions to **LeetCode** and **GeeksforGeeks** problems, implemented in **C++**.

This repository tracks my problem-solving practice, Data Structures & Algorithms (DSA) concepts, and my progress toward coding interviews and placements.

---

## 📂 Repository Structure

```
Leetcode-GeeksforGeeks/
│
├── Stack-queue/     # Problems based on Stack and Queue
├── tree/            # Problems based on Trees (Binary Tree, BST, etc.)
└── .gitignore
```

| Folder | Topic | Description |
|--------|-------|-------------|
| `Stack-queue` | Stack & Queue | Monotonic stack, next greater element, queue using stack, etc. |
| `tree` | Trees | Traversals, recursion on trees, BST problems, etc. |

> More topics (Arrays, Linked List, Graphs, DP, etc.) will be added as I progress.

## ▶️ How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/vaishnaviimahajann/Leetcode-GeeksforGeeks.git
   cd Leetcode-GeeksforGeeks
   ```

2. Compile any solution
   ```bash
   g++ -o solution path/to/file.cpp
   ```

3. Run it
   ```bash
   ./solution
   ```
